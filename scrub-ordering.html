Required Uniform

Scrub ordering details
for ZION families.

Use this guide to order the required RMF scrub set, provide the embroidery logo, and request an email mockup before your order is processed.

Order Early

Orders with custom embroidery typically take 15-20 business days for delivery. Please order early so your student's scrubs arrive before school begins.

Step 01

Choose an approved RMF scrub set.

Students may choose any solid color. Please order one of the approved RMF scrub options below.

Poplin Children's Scrub Set → Children's Jogger Scrub Set →
Step 02

Download the embroidery logo.

Use this file when placing the embroidery order. It is the ZION outSchool embroidery logo for the 2026-2027 uniform.

Download Embroidery Logo →
Checkout Notes

Ask for a mockup before the order is processed.

Embroidery size can be difficult to specify exactly because the right size changes as scrub sizes increase or decrease. During checkout, use the order notes section to request an email mockup before RMF processes the order. Once you receive the mockup, you can ask them to increase or decrease the embroidery size so it looks attractive on your student's scrubs.

Suggested order note

Please email me a mockup of the ZION outSchool embroidery before processing this order. I would like to approve the embroidery placement and size before the scrubs are embroidered.

After ordering, submit the purchase through ClassWallet for reimbursement.
